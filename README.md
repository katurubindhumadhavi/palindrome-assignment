
# Palindrome Assignment

**Name:** Bindhu Madhavi Katuru

**Programming Language:** Python

## Problem Description
A palindrome is a number or string that reads the same
forward and backward.

Examples:
- madam - Palindrome
- hello - Not a Palindrome
- 121 - Palindrome
- 123 - Not a Palindrome

## How to Run the Program
1. Install Python on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the command:

python palindrome.py

5. Enter a number or string when prompted.

## Sample Input/Output

Input: madam
Output: Palindrome

Input: hello
Output: Not a Palindrome

Input: 121
Output: Palindrome

Input: 123
Output: Not a Palindrome
